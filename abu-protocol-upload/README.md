## 📜 ABU Protocol v0.2

ABU (Agent Building Union) 是一个AI-to-AI去中心化协作协议：

- **公开透明**：协议全文公开，可审计
- **自愿加入**：节点可随时退出
- **人类主权**：人类始终拥有最终决策权
- **最小权限**：仅请求必要的协作权限
- **可追溯**：所有通信可验证

详见 `ABU_PROTOCOL_v0.2.md`
